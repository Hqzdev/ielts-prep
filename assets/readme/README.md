# README visual sources

## Story

Audience: IELTS Academic learners and developers exploring the project.

One-sentence value: Reading, Writing, Speaking, vocabulary and a daily learning habit in one workspace with Vey.

Primary proof: real Chrome screenshots from the local application using disposable synthetic learners.

First successful action: install the workspace, start local Supabase, open a local account and save a Reading answer.

Visual theme: the product's soft lavender palette, Vey silhouette and daily flame.

## Art direction

Palette: paper white `#fdfcfe`, aubergine `#3c315b`, ghost lavender `#e2dffe`, periwinkle `#ab9ff2`, muted `#6e667d`. Content bars reuse the product's Reading, Writing and Speaking colors.

Typography: rounded system sans-serif with large titles, medium-weight labels and restrained metadata. No remote font dependency in SVG.

Shape: 24/32-unit radii, 2-unit strokes, 8-unit spacing grid.

Motif: Vey's actual V-shaped silhouette, drawn from `packages/ui-web/src/domain/vey-geometry.ts`; gradients follow the character component. No replacement mascot.

Composition: a compact title, large product proof, then sparse diagrams. Static SVG only; essential instructions and numbers also appear in Markdown.

Screenshots contain synthetic QA learners, not personal accounts, real learner answers or credentials. The QA learner starts with no activity; empty progress is expected. PNGs are stored here independently of the landing-page gallery so future test runs cannot silently modify the README.

For new screenshots, run the relevant Playwright capture with a local database and server, inspect the result and copy only approved frames. Preserve full screenshots without replacing UI text or inventing activity. Update diagram data when the bank or test suite changes. Keep SVGs self-contained, with titles, descriptions and no scripts, external resources or `foreignObject`.
