# Проверка точности AI

Адаптеры реализованы, но достоверность band не следует из успешной сборки или проверки JSON. До независимой калибровки `ASSESSMENT_WRITING_ENABLED=false` и `ASSESSMENT_SPEAKING_ENABLED=false`.

## Источники экспертных примеров

[IELTS: материалы для понимания оценок](https://ielts.org/organisations/ielts-for-organisations/understanding-ielts-scoring/resources-for-setting-your-ielts-scores) содержит descriptors, ответы и комментарии экзаменаторов. [IELTS Academic sample questions](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test) содержит задания и материалы Speaking. Эти источники служат отправной точкой внутреннего набора; они не добавляются автоматически в публичный каталог.

Необходимо собрать отдельные наборы для Writing Task 1, Writing Task 2 и Speaking. Для Task 2: минимум пять работ настройки и десять независимых работ. Стенд применяет такой же минимальный порог к каждой включаемой части Speaking и к Task 1. Экспертную оценку нельзя заменять самооценкой или оценкой другой модели.

## Формат и запуск

Полная схема находится в `scripts/calibration-corpus.schema.json`. Каждый элемент содержит `id`, `split` (`tuning` или `holdout`), `source`, `expertBand`, полный `task`, текст `answer` либо список `audio` с `path` и `questionIndex`. Пути аудио разрешаются относительно файла набора. Нужен WAV PCM mono 16 kHz.

```sh
pnpm assessment:evaluate --schema
pnpm assessment:evaluate --corpus /absolute/path/corpus.json
pnpm assessment:evaluate --corpus /absolute/path/corpus.json --live
```

Без `--live` проверяются только структура, источник, уникальность, разделение выборок и доступность аудио. С `--live` выполняются реальные платные запросы по ключу из веб-окружения. Каждая работа holdout оценивается дважды для проверки стабильности. В логи ответы не выводятся; отчёт содержит идентификаторы и числовые результаты. По умолчанию он сохраняется в закрытой игнорируемой папке `.local`.

## Порог допуска

- Средняя абсолютная ошибка на holdout не больше 0,5.
- Не менее 80% результатов отличаются от эксперта максимум на 0,5.
- Между двумя прогонами одной работы разница не больше 0,5.
- Нет пропущенных результатов на пригодных для оценки примерах.
- Цитаты и отметки времени прошли серверную проверку.
- Эксперт отдельно проверил обнаружение неверных данных Task 1, полноту раскрытия cue card и оценку произношения по аудио.

Последние качественные критерии требуют просмотра человеком: стенд не выдаёт формальное прохождение за доказательство корректной методики. Смена модели или рубрики требует нового прогона. Для Speaking полезно включить разные акценты, темп, короткие ответы, тишину и плохие записи.

## Текущее состояние

Контракты, исправление структуры, отсутствие оценки по одному тексту, расчёт band и интерфейс результата проверены локально. Экспертный корпус не предоставлен; реальные запросы Gemini не выполнялись. Оба флага оценивания оставлены выключенными. Тестовая оценка 6.5 используется только в изолированном визуальном тесте и удаляется вместе с тестовым аккаунтом.
