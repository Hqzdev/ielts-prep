# ADR 003: общие дизайн-данные

Дата: 2026-09-06. Статус: принято.

`packages/design-tokens/src/tokens.json` хранит 74 CSS-значения, связи семантических цветов, веса, радиусы и описание шрифтов. `assets` содержит Вея, огонёк, favicon, файлы шрифтов и лицензии. Генератор воспроизводит CSS и веб-ресурсы по прежним адресам; проверка сравнивает байты.

`vey-motion.json` содержит спокойную позу, именованные состояния и параметры сглаживания. Веб-модель использует эти значения, а DOM-контроллеры и SVG остаются в ui-web. Swift читает JSON, но отрисовка и аудиореакция будут собственными платформенными адаптерами.

Миграция сохраняет цвета, Nunito Sans/OrbitDisplay, размеры и текущие эмоции. Новые названия внутренних пакетов не меняют видимые имена Vey/Вей и Veylo.
