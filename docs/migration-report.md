# Результат миграции Veylo

Дата: 2026-09-06. Локальная миграция согласованного плана завершена. Ветка: `codex/layered-monorepo`. Исходное состояние сохранено коммитом `b0f20a3`.

## Реализовано

- pnpm-монорепозиторий: `apps/web`, пять общих пакетов, отдельные Python- и Swift-инструменты, `infra/supabase`, корневые команды и конфигурации.
- Реальные слои backend: Domain, Application, Infrastructure, Composition. Next.js/CLI/Workflow являются Interfaces. В application 20 модулей сценариев; хранилища, AI, часы, идентификаторы и очередь внедряются через порты.
- Каталог, practice/черновики, оценивание, план, огоньки, словарь, Arcade, чат/аудио, профиль и администрация используют перенесённые сценарии. Старые бизнес-реализации удалены.
- OpenAPI 3.1 на 46 операций `/api/v1`; сгенерированные TS-типы используются вебом. Прежние `/api`-адреса сохранены как тонкие переэкспорты. Добавлено чтение профиля для будущего native-клиента.
- Cookie и проверенный Bearer используют общую политику прав. Ошибки, ревизии, повторы, NDJSON, WAV и часовые пояса описаны в контракте.
- 74 дизайн-токена, 10 ассетов, параметры поз и сглаживания Вея выделены в общие данные. Шрифты, цвета, изображения и поведение интерфейса сохранены.
- JSON-логи HTTP/AI/очереди с request ID, trace ID, исходом и длительностью. Учебные тексты, аудио и секреты в эти логи не включаются.
- Корневые ESLint/Prettier/TypeScript, Black/Ruff, проверка Swift-формата, Git hooks, Conventional Commits, Verify CI, Release Please и CODEOWNERS для подтверждённого владельца @Hqzdev.
- README пакетов, ADR, карта модулей, правила разработки и runbooks деплоя, отката, восстановления и диагностики.

Полный браузерный прогон покрывает регистрацию/подтверждение email, приглашение, onboarding, восстановление пароля, черновик/offline/reload, Reading, результаты, словарь, серию, Arcade, речь/тишину/шум, retry TTS, закрытие микрофона, эмоции Вея, reduced motion и узкие экраны.

Проверки аудио используют подготовленные файлы и заглушки ответов AI; это не калибровка модели и не испытание физического микрофона. Сборка сохраняет предупреждения стороннего ONNX о динамическом require. Swift toolchain сообщает отсутствующие локальные search paths, но компиляция и запуск успешны; предупреждений о пропущенных nullable-схемах нет.

## Сохранность данных

Все 11 ранее применённых SQL-миграций сохранены побайтно. Project ID `ielts-prep` не изменён. Резервные копии базы и Storage находятся в закрытой игнорируемой `.local/migration-backup`; custom PostgreSQL-архив проверен на чтение.

После тестов в исходной базе осталось столько же записей, сколько до переноса: profiles — 5, attempts — 23, learning_days — 1, storage.objects — 0. Временный проект чистой установки удалён. Рабочая база не сбрасывалась.

Старые тесты Reading и анимации рта обновлены для видимых элементов Next.js и текущего SVG-Вея. Тест галереи по умолчанию пишет в `.local`, поэтому проверки больше не меняют продуктовые изображения.

## Внешняя часть

Origin — публичный `Hqzdev/ielts-prep`, текущая учётная запись имеет ADMIN; в удалённом репозитории пока нет default branch. Код подготовлен локально, публикация в origin и GitHub Actions не выполнялись. CODEOWNERS назначен реальному владельцу; второй ревьюер для критичных путей ещё нужен.

Branch protection, cloud IaC, staging/production, secret store, deployment approvals, централизованные метрики и внешнее резервное копирование требуют назначения окружений и отдельной настройки. Они не заявляются включёнными. Приложения iOS/macOS остаются следующим этапом; для них подготовлены контракт, авторизация и общие дизайн-данные.

Команды воспроизведения приведены в корневом README. Локальные подробные результаты сохранены в игнорируемой `.local/verification-summary.json` и журналах проверок.
