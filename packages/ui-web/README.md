# UI Web

SVG-Вей, модели лица/движения, управление взглядом и веб-форматирование. Компоненты используют общие дизайн-данные; DOM, requestAnimationFrame и IntersectionObserver остаются здесь.

```sh
pnpm exec vitest run apps/web/tests/vey-motion.test.ts
pnpm typecheck
```

Команды выполняются из корня. Учебные экраны и браузерное аудио находятся в apps/web. Для SwiftUI эти контроллеры не импортируются.
