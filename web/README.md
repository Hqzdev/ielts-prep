# IELTS Prep

Рабочая среда для IELTS Academic на Next.js. Интерфейс, учебные объяснения и ответы AI — на английском. Словарь содержит английские определения и примеры. Веб-приложение находится в этой папке; исходный Python-генератор в корне проекта остаётся самостоятельным инструментом.

## Открыть приложение

На подготовленном компьютере:

```sh
cd /Users/yaroslavfairfieldd/Desktop/ielts-prep/web
pnpm dev
```

Откройте [локальное приложение](http://127.0.0.1:3000/login) и нажмите **Open local account**. Это настоящий аккаунт локального Supabase с личной историей. Такой вход доступен только в режиме разработки с локальной базой; в production используется обычная авторизация.

Для новой установки нужны Node.js 24, pnpm и Docker Desktop либо OrbStack:

```sh
pnpm install --frozen-lockfile
pnpm local:setup
pnpm dev
```

`local:setup` запускает локальный Supabase, применяет миграции, создаёт закрытый файл `.env.local` и импортирует контент. Существующие настройки и ключи сохраняются. Генератор и его файл `.env` не используются веб-приложением.

## Что работает

- Каталоги Writing, Speaking, Reading с поиском, темами, форматами, статусами и фильтрами в URL. Сайдбар раскрывается внутри меню; профиль закреплён снизу.
- 146 упражнений: 40 Writing, 60 Speaking, 46 Reading. Все 120 исходных заданий сохраняют идентификаторы. Добавлены 26 упражнений для остальных форматов Reading; они используют два новых авторских текста.
- Writing Task 1 и Task 2, графики, таблицы, линейные и циклические процессы. Автосохранение, локальная копия, пауза, серверный строгий дедлайн, исправления отдельными попытками.
- Все 14 вариантов интерфейса Reading, серверная проверка по закрытому ключу, учебный band, набранные баллы, точность, цитаты из текста и объяснения на английском. Для коротких упражнений band обозначен как приблизительный; [методика расчёта](docs/reading-bands.md).
- Speaking: микрофон, VAD, последовательность готовых вопросов, подготовка и монолог Part 2, пауза в тренировке, перезапись, загрузка WAV, воспроизведение. Без TTS-ключа вопрос можно прочитать перед записью.
- Аркада с шариком и пилами. Речь определяется локально; тишина и шум не заменяют речь. Раунд заканчивается при столкновении либо через две минуты.
- Главная с недельным планом, продолжением попытки и статистикой; личный кабинет; 300 слов в 15 темах, личные слова и два вида мини-тестов.
- Настоящие адаптеры Gemini для оценивания, расшифровки, озвучки, чата и подготовки словарных записей. Фоновая проверка через Workflow, проверка цитат и структуры, ограниченные повторы, сохранение результата и защита от повторной обработки.
- Приглашения, email и Google через Supabase Auth, административная область, версии контента, RLS, закрытое аудиохранилище и удаление аудио через 30 дней.

## Подключение AI

В `web/.env.local` задайте `GEMINI_API_KEY`. Ключ доступен только серверу. Модели задаются через `GEMINI_TEXT_MODEL`, `GEMINI_AUDIO_MODEL`, `GEMINI_TTS_MODEL`; значения по умолчанию соответствуют согласованному плану. Для чата, словаря и озвучки достаточно ключа.

Оценивание дополнительно защищено флагами `ASSESSMENT_WRITING_ENABLED` и `ASSESSMENT_SPEAKING_ENABLED`. Включать их следует после проверки качества на экспертных работах. См. [проверку оценивания](docs/assessment-quality.md).

Без ключей приложение сохраняет ответы и записи. Reading рассчитывает результат и учебный band по ключу; словарные тесты тоже работают. Оценки Writing и Speaking и AI-разборы не подставляются. После подключения сохранённую работу можно отправить на проверку отдельной кнопкой.

## Проверки

```sh
pnpm content:check
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

С запущенными локальным Supabase и приложением:

```sh
TEST_INTEGRATION=1 pnpm exec vitest run tests/api.integration.test.ts tests/load.integration.test.ts
pnpm exec playwright install chromium webkit
pnpm test:e2e
```

Браузерные сценарии используют установленный Chrome и WebKit. Голосовые образцы подаются в изолированный Chromium через fake microphone; ваш микрофон в тестах не записывается. Тестовые аккаунты удаляются после сценария. Результат 6.5 в визуальном тесте помечен `visual-test-fixture` и не является оценкой AI.
