# IELTS practice bank

120 самостоятельных тренировочных заданий на английском языке: по 20 в каждом JSON-файле. Материалы составлены ассистентом без вызовов Gemini API. Это не официальные вопросы IELTS.

| Файл | Содержимое |
| --- | --- |
| [writing_task2.json](writing_task2.json) | 20 эссе-заданий: по 3 opinion, discussion, advantages/disadvantages и outweigh; по 2 causes/solutions, problem/solution, two-part и positive/negative |
| [writing_task1_academic.json](writing_task1_academic.json) | По 4 bar chart, line graph, pie chart, table и process diagram |
| [speaking_part1.json](speaking_part1.json) | 20 бытовых тем, по 4 вопроса: всего 80 вопросов |
| [speaking_part2.json](speaking_part2.json) | 20 карточек с опорными пунктами и двумя завершающими вопросами |
| [speaking_part3.json](speaking_part3.json) | 20 обсуждений по 5 вопросов, связанных с карточками Part 2: всего 100 вопросов |
| [reading_passage.json](reading_passage.json) | 20 текстов по 654–702 слова, по 8 вопросов TRUE/FALSE/NOT GIVEN: всего 160 вопросов |

## Как пользоваться

Каждый файл — JSON-массив. Выбирай любой объект с `used: false`; после тренировки можно вручную поменять значение на `true`. У каждого задания есть постоянный `id`. Существующий файл `tasks.json` в родительской папке не изменён.

Для Writing Task 2 используй `prompt` и `instructions`. На ответ отводится примерно 40 минут, минимум 250 слов.

В Speaking Part 2 готовая карточка находится в `cue_card`: одна минута подготовки, затем речь на 1–2 минуты. В `rounding_off_questions` лежат короткие завершающие вопросы. Найди обсуждение Part 3 с соответствующим `part2_id`, чтобы продолжить ту же тему.

В Reading сначала читай `paragraphs` и отвечай на `questions`. Затем открой отдельный `answer_key`: у каждого ответа есть цитата из указанного абзаца и объяснение. Исследования, организации и события внутри текстов — вымышленные учебные ситуации. Все ответы определяются текстом, а не внешними знаниями. Это упражнения на один вид вопросов, не полноценные варианты экзамена Reading.

В Task 1 содержатся синтетические данные, подписи и единицы измерения либо последовательность стадий процесса. Картинки не построены: `visual_status` равен `not_rendered`. Для тренировки с экзаменационным видом задания сначала нужно отобразить эти данные как график, таблицу или схему. На ответ — около 20 минут, минимум 150 слов.

## Проверка набора

Проверены количество объектов, уникальность ID, структуры данных, соответствие карточек Part 2 обсуждениям Part 3, суммы круговых диаграмм, длины Reading, нумерация вопросов и точное наличие цитат в абзацах. Формулировки и ключи дополнительно просмотрены на смысловую согласованность. Независимую проверку сертифицированным преподавателем материалы не проходили.
